# Метрики успадкованого модуля

## До рефакторингу

Спосіб вимірювання: вручну. LOC — рядки без порожніх і без рядків лише з коментарем (дужки рахуються).
CC = 1 + кількість if, else if, case, for, foreach, while, catch, &&, ||, ??, тернарних операторів.
Для перевірки рахунок повторено скриптом, який шукає ті самі ключові слова в тілі методу; числа збіглися.

| Метод | LOC | CC | Глибина вкладеності | Параметрів |
|-------|-----|----|---------------------|------------|
| Handle | 80 | 17 | 4 | 11 |
| Preview | 28 | 9 | 2 | 3 |
| DescribeClient | 10 | 3 | 1 | 1 |
| DumpLog | 6 | 2 | 1 | 0 |
| Файл загалом | 149 | — | — | — |

Розрахунок CC для Handle:

| Точка | Кількість |
|-------|-----------|
| if (items != null) | 1 |
| if (items.Count > 0) | 1 |
| if (state == "new" ...) та оператор \|\| | 2 |
| if (clientMail != null ...) та оператор && | 2 |
| два цикли for | 2 |
| три перевірки виду клієнта (if / else if / else if) | 3 |
| три перевірки межі знижки if (> 500m) | 3 |
| if (сума < 1000m) | 1 |
| if (sendMail) | 1 |
| Разом | 16 |

CC = 1 + 16 = 17.

Додатково:
- відповідальностей класу: 7 (перевірка входу, підсумок, знижки, доставка, форматування звіту, журнал, опис клієнта);
- дубльованих рядків між Handle і Preview: 19;
- магічних чисел: 7 різних, 25 входжень.
