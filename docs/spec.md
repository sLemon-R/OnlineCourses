# Специфікація OnlineCourses (СР3, варіант 17)

## 1. Межі системи

| Входить | Свідомо не входить |
|---|---|
| каталог курсів і навчальних груп з кількістю місць | онлайн-оплата, платіжний шлюз |
| довідник слухачів з пройденими курсами | особистий кабінет, розмежування прав |
| зарахування до груп з перевіркою місць і передумов | розклад занять і викладачі |
| знижка за пакет курсів | податковий облік, акти й рахунки |
| відрахування й переведення між групами одного курсу | графічний інтерфейс, вебдоступ |
| оплата заявки за станами | повернення коштів після старту навчання |
| пошук заявок, звіт «наповнюваність груп» | база даних |
| збереження груп у файл JSON | імпорт з інших систем |

## 2. Словник домену

| Термін | Ідентифікатор | Значення |
|---|---|---|
| курс | Course | програма навчання з кодом, назвою, ціною й передумовами |
| передумова | Course.Prerequisites | коди курсів, які слухач має пройти раніше |
| навчальна група | CourseGroup | набір слухачів одного курсу з обмеженою кількістю місць і датою старту |
| місткість групи | CourseGroup.Capacity | загальна кількість місць |
| вільні місця | CourseGroup.FreeSeats | місткість мінус зайняті місця |
| наповненість | CourseGroup.FillPercent | зайняті місця у відсотках, до десятих |
| слухач | Listener | людина, що навчається; має пошту й ознаку постійного слухача |
| постійний слухач | Listener.IsReturning | уже навчався на платформі, має надбавку до знижки |
| пройдені курси | Listener.CompletedCourses | коди курсів, що зараховуються як передумови |
| заявка | Enrollment | документ зарахування зі станом і позиціями |
| позиція заявки | EnrollmentLine | курс, кількість місць і ціна |
| стан заявки | EnrollmentStatus | New, Paid, InProgress, Completed, Cancelled |
| знижка за пакет | PackageDiscount | знижка за кількість курсів в одній заявці |
| порушення правила | DomainRuleException.Rule | код правила, наприклад group.full |

## 3. Сценарії використання

### UC-01. Зарахувати слухача
- Дійова особа: адміністратор курсів.
- Мета: записати слухача в одну чи кілька груп і отримати суму до сплати.
- Передумова: слухач є в довіднику, групи є в каталозі.
- Основний перебіг: 1) адміністратор вводить номер слухача; 2) вводить коди груп через кому; 3) система перевіряє, що кожна група ще не стартувала; 4) перевіряє передумови курсу; 5) перевіряє вільні місця; 6) займає місця в усіх групах; 7) створює заявку в стані New; 8) показує номер заявки й суму зі знижкою за пакет.
- Альтернативи: 1а) слухача немає — повідомлення listener.exists; 2а) групи немає — group.exists; 3а) група стартувала — group.started; 4а) бракує передумови — course.prerequisite; 5а) місць немає — group.full. У всіх альтернативах жодне місце не займається.
- Постумова: місця зайняті, заявка New збережена.
- Тести: GroupEnrollmentServiceTests.Enroll_*.

### UC-02. Відрахувати або перевести слухача
- Дійова особа: адміністратор курсів.
- Мета: звільнити місце чи перенести слухача в іншу групу того самого курсу.
- Передумова: слухач навчається в початковій групі.
- Основний перебіг (переведення): 1) адміністратор вводить слухача; 2) вводить початкову й цільову групи; 3) система перевіряє, що курс той самий; 4) займає місце в цільовій групі; 5) звільняє місце в початковій.
- Альтернативи: 3а) курси різні — group.course; 4а) у цільовій немає місць — group.full, слухач лишається в початковій; 2а) слухача немає в групі — group.member. Відрахування — лише кроки 1, 2 і 5.
- Постумова: місце звільнено або перенесено.
- Тести: Transfer_*, Expel_*.

### UC-03. Оплатити заявку
- Дійова особа: адміністратор (за квитанцією слухача).
- Мета: перевести заявку в стан Paid.
- Передумова: заявка в стані New.
- Основний перебіг: 1) вводиться номер заявки; 2) вводиться сума; 3) система рахує суму зі знижкою; 4) переводить заявку в Paid.
- Альтернативи: 1а) заявки немає — enrollment.exists; 3а) заявка вже оплачена чи скасована — enrollment.state; 3б) сума менша — enrollment.amount.
- Постумова: стан Paid.
- Тести: Pay_*, StatusTransitionTests.

### UC-04. Знайти заявки
- Дійова особа: адміністратор.
- Мета: побачити заявки слухача та/або в певному стані.
- Основний перебіг: 1) вводиться номер слухача або порожньо; 2) вводиться стан або порожньо; 3) система показує заявки за номером.
- Альтернативи: 3а) нічого не знайдено — «Знайдено заявок: 0»; 2а) стан введено з помилкою — фільтр за станом не застосовується.
- Тести: SearchAndReportTests.Find_*.

### UC-05. Звіт «наповнюваність груп»
- Дійова особа: адміністратор.
- Мета: побачити, які групи заповнені, а куди ще можна записувати.
- Основний перебіг: 1) вибирається пункт звіту; 2) система бере групи, що стартують від сьогодні; 3) сортує від найбільш заповненої, далі за кодом; 4) друкує таблицю «група, курс, місць, зайнято, %».
- Альтернативи: 2а) груп немає — «Груп для звіту немає»; 3а) однакова наповненість — порядок за кодом.
- Тести: SearchAndReportTests.Rows_*, Text_*.

### UC-06. Зберегти дані
- Дійова особа: адміністратор.
- Мета: зберегти групи з зарахованими слухачами між запусками.
- Основний перебіг: 1) вибирається пункт «Зберегти»; 2) групи записуються в data/groups.json; 3) при наступному запуску файл читається й групи відновлюються.
- Альтернативи: 2а) теки data немає — файл не записується, програма повідомляє про помилку; 3а) файлу немає — використовуються стартові дані.
- Тести: SearchAndReportTests.Json_RoundTrip_KeepsGroupAndListeners.

## 4. Таблиця рішень: знижка за пакет

| Курсів у заявці | Слухач | Ставка |
|---|---|---|
| 1 | новий | 0 % |
| 1 | постійний | 3 % |
| 2 | новий | 5 % |
| 2 | постійний | 8 % |
| 3 і більше | новий | 10 % |
| 3 і більше | постійний | 13 % |

- Знижка = сума × ставка, округлення до копійок від нуля (MidpointRounding.AwayFromZero).
- Верхня межа знижки — 1500 грн на заявку.
- Нульова сума дає нульову знижку; від'ємна сума чи нуль курсів — помилка програміста (ArgumentOutOfRangeException).

Контроль місць: зарахування можливе, лише якщо в групі є вільне місце, група ще не стартувала й слухач пройшов усі передумови курсу.
