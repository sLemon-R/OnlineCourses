# Посібник користувача OnlineCourses

## Запуск

```
dotnet run --project OnlineCourses.App
```

Після запуску видно версію, кількість слухачів і груп та меню:

```
OnlineCourses v1.0.0
Слухачів: 60, груп: 12

1 Зарахувати  2 Відрахувати  3 Перевести  4 Оплатити  5 Пошук  6 Звіт  7 Зберегти  0 Вихід
Пункт:
```

Номер пункту вводиться цифрою й Enter. Слухачі мають номери 1–60; кожен третій (3, 6, 9...) — постійний слухач, який уже пройшов CS-101. Групи: CS-101-A/B, CS-201-A/B, DB-101-A/B, WEB-101-A/B, QA-101-A/B, AI-201-A/B, по 12 місць. Для CS-201 і AI-201 потрібен пройдений CS-101.

## Сценарії

### Зарахувати на два курси (UC-01)

```
Пункт: 1
Слухач: 1
Групи через кому: CS-101-A, DB-101-A
Заявка № 1, до сплати 4940.00 грн
```

Дві групи — знижка 5 %: (2400 + 2800) × 0,95 = 4940,00 грн.

### Курс без передумови (UC-01, відмова)

```
Пункт: 1
Слухач: 2
Групи через кому: CS-201-A
Відмова [course.prerequisite]: Спершу потрібно пройти курс CS-101
```

### Пакет із трьох курсів для постійного слухача

```
Пункт: 1
Слухач: 3
Групи через кому: CS-201-A, AI-201-A, DB-101-B
Заявка № 2, до сплати 8787.00 грн
```

Три курси й постійний слухач — 13 %: (3200 + 4100 + 2800) × 0,87 = 8787,00 грн.

## Повідомлення про помилки

| Повідомлення | Що означає | Що робити |
|---|---|---|
| Помилка вводу: потрібне ціле число більше 0 | у номер введено літери чи 0 | ввести номер ще раз |
| Помилка вводу: сума — число з крапкою | сума з комою або літерами | ввести, наприклад, 4940.00 |
| Відмова [listener.exists] | слухача з таким номером немає | перевірити номер (1–60) |
| Відмова [group.exists] | коду групи немає в каталозі | ввести код точно, наприклад CS-101-A |
| Відмова [group.started] | група вже почала навчання | вибрати іншу групу того самого курсу |
| Відмова [course.prerequisite] | слухач не пройшов потрібний курс | спершу записати на курс-передумову |
| Відмова [group.full] | у групі немає місць або слухач уже в ній | вибрати іншу групу |
| Відмова [group.course] | переведення між різними курсами | переводити лише в групу того самого курсу |
| Відмова [group.member] | слухача немає в групі | перевірити групу й номер слухача |
| Відмова [enrollment.amount] | сума менша за вартість зі знижкою | ввести повну суму |
| Відмова [enrollment.state] | заявка вже оплачена чи скасована | нічого, повторна оплата не потрібна |
| Невідомий пункт меню | введено пункт, якого немає | ввести 0–7 |

## Дані й резервна копія

- Пункт 7 записує групи з зарахованими слухачами у `data/groups.json` поруч із запуском. Під час наступного запуску файл читається автоматично.
- Журнал дій — `logs/app.log` (час, рівень, сценарій, повідомлення; без імен і пошти слухачів).
- Резервна копія — скопіювати теку `data` в інше місце. Щоб почати зі стартових даних, видалити `data/groups.json`.
- Заявки зберігаються лише до закриття програми.
